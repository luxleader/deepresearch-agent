# AI 技术方案调研 DeepResearch

本项目用于根据使用约束研究 AI 技术方案，查询官方文档和论文，输出可追溯的方案对比与建议。

当前阶段是设计与实施计划，尚未实现产品代码、接入模型/搜索接口或完成联网评测。仓库记录真实进度，不将规划功能写成已实现能力。

## 开源基础

主底座选用 [GPT Researcher](https://github.com/assafelovic/gpt-researcher)，固定提交 `3582a6841fe7dc801e2a34e34ee408641aea9bce`。本项目计划复用它的检索、抓取和基础研究能力，新增领域约束、证据核验、缺口补搜、任务恢复与可复现评测；这些新增能力当前均未实现。

用户负责需求与结果评估，Codex 负责实现和测试。项目成果与贡献按实际过程记录。
