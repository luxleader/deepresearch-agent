# DR-20261014-006 事务状态与调用预算

## 需求来源
长任务持久化、崩溃恢复以及预算不能因并发被超额使用。

## 改动
SQLite WAL 存储任务、步骤、来源、证据和单调事件序号。调用前事务预留；完成 packet 单独保存，旧状态不会覆盖 calls 或已完成 packet。补充运行锁与进程中断识别。

## 实际验证
模块不存在时 storage 测试失败；实现后全套 pytest：25 passed。覆盖重新打开数据库保留计数、并发预留最多一次、两个结果与旧状态合并、已完成不重复和事件分页。

## 限制与回退
只保证已保存步骤不重复；外部调用成功但本地未保存的窗口仍可能重复付费。单进程本机场景，不支持多个服务实例共用此恢复机制。GitHub 传输暂不可用，保留本地签名提交。回退用 revert。
