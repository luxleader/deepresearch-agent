# DR-20261014-014 · 评测即时保存与失败恢复

## 需求与改动
审查指出基线仅在内存，后续失败会丢失已付费结果及此前题目。现在每个 arm 完成立即原子保存报告、完整 packet、来源、用量；失败记录状态与尝试错误，增强任务 ID 提前保存。相同 output、题目、配置、模式与材料复用成功基线，恢复增强侧。CLI 每题更新汇总与盲评文件，失败题显示未生成报告。

## 验证
先以“增强失败后恢复”和“第一题成功、第二题失败”用例复现未保存错误，两项失败；修复后全套 52 passed，ruff 通过。核对成功基线恢复时仅调用一次、正文保存、失败历史保留、两个题目均在本机缓存。

## 限制与回退
外部成功与落盘之间仍有窗口；失败供应商未返回的费用无法统计，不能记为零。恢复使用相同 --output 目录，运行数据保持本机并被 Git 忽略；不支持多进程同时写同一评测目录。回退用 revert 会恢复结果丢失风险。
