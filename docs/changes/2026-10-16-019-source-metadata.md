# DR-20261016-019 · 来源标题与时间依据

## 需求来源与改动
继续实现原设计中的来源版本/日期披露。HTML 读取保留 title/og:title、明确 meta/time/JSON-LD 声明的发布日期和修改日期，记录 date_basis 和元数据提示；不执行脚本，不从正文日期猜测。冲突发布日期保持未知。Source 新字段有默认值，旧数据库可继续读取。适配器和 Markdown 保留这些字段；删除旧的重复正文解析器。

## 验证
5 项元数据回归先失败，补齐字段与解析后通过；额外先复现“旧发布、新修改”仍标为历史证据，再修复。最终全套 61 passed，ruff 通过。覆盖无效日期、日期冲突、修改日期不能当发布日期、JSON-LD 与正文隔离、SDK 透传和截止日后的修改。

## 限制与设计决策
元数据是站点自报，未独立认证，也不能证明历史快照。任一明确发布/修改日期晚于截止日，当前正文不支持当时事实。未知日期继续披露。PDF 本批未增加发布日期推断，创建时间不作为发布时间；无 OCR。来源性质/版本不由域名或标题自动猜测。

## 备份、溯源与回退
同 ID 签名提交、上传实施分支并最终回读。字段向后兼容，回退用 revert；回退后新元数据运行记录可能需旧字段迁移，不应丢弃原缓存。
