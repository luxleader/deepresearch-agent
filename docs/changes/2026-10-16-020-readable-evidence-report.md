# DR-20261016-020 · 可读报告、证据定位与完整导出

## 需求来源与改动
继续原方案的演示应用和可追溯导出。报告由安全 DOM 展示研究范围、约束、摘要、对比、事实/建议、未知项；引用按钮定位证据，证据定位完整来源和日期。标签页支持方向键/Home/End；刷新恢复原问题和约束，读取进度失败可重试，过期任务 ID 给出新建提示。新增 report-view.js，与现有页面风格保持一致。

JSON 保留既有 claims 等报告字段，新增 schema_version=1、请求/规划、完整原文、证据、时间及已保存步骤用量，标记统计不完整。接口始终校验完成报告再导出，文件以 attachment 下载。网页资源和接口禁用缓存；版本参数清除已有旧缓存。

## 验证
JSON 追溯回归先因缺少 schema_version 失败，修复后可逐命题回溯原文；实际浏览器发现仍缓存旧脚本，缓存回归先失败，增加 no-store 后更新生效。最终 63 passed、ruff 通过，两份 JS 的 node --check 通过。

实际浏览器核对结构化报告、事实→证据→完整来源、标签页方向键、刷新恢复输入。手机宽度测试无横向溢出（clientWidth=scrollWidth=375）；测试特殊输入 <img ...> 仅显示文本，报告中没有 img 节点。缩放已复原。

## 限制与设计决策
本轮仅人工构造回放，用户明确密钥暂未准备；不进行真实模型验证。JSON 含本机来源正文，默认不上传；用量仅为已保存研究步骤，不声称总金额。引用语义仍需人工核对。UI 行为由浏览器实测，未引入额外前端运行依赖。
