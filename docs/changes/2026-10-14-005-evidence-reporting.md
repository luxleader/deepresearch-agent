# DR-20261014-005 证据与全报告核验

## 需求来源
实现关键结论证据核验，并避免摘要、对比表绕过校验。

## 改动
新增证据收集和报告验证/渲染。原文片段规范化后必须存在；截止日后证据降级；所有显示段落引用同一 claims 账本。事实必须复用对应已核验命题，不能用有效 evidence ID 偷换另一条结论。引用链接由来源记录生成；未知日期显式说明。

## 实际验证
新增模块前 tests/test_evidence_reporting.py 因缺少模块失败；实现后完整 pytest：20 passed。覆盖不存在的 claim/evidence、伪造 quote、冲突、日期和引用渲染。语义 supported 是模型信号，仍需要人工抽查，未做联网效果评测。

## 决策与限制
固定事实命题使用证据账本文字；建议明确标注，不作为已验证事实。Markdown 在页面将按纯文本展示，防止来源 HTML 进入页面。GitHub 网络仍失败，本地签名历史先保留，稍后重试备份。回退使用 revert。
