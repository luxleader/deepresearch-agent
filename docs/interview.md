# 项目讲解与验收

可以解释的工程内容：约束变为维度，复用固定 GPT Researcher，正文证据账本贯穿摘要和对比，针对缺口补搜，调用前事务预留和已保存步骤恢复，界面核对原文/未知项。

运行一次问题并解释：为什么“片段存在”不同于“支持结论”，为什么成功但未保存的请求可能重复付费，为什么外层 8 次不是金额上限。不要只背功能列表。

当前没有真实联网验收、人工质量评分或提升数字；不能写提高准确率多少、解决幻觉或降低成本多少。代码由 Codex 实现，用户负责需求/评估，个人项目表述应以自己掌握的模块与实测为准。

用户验收步骤：

1. 离线提交知识库示例，核对页面、过程、导出和刷新。
2. 本机配置 Qwen-Plus/Tavily，提出三个真实问题，逐条核对关键命题与日期。
3. 确认题目和标注协议后执行留出/盲评，保留失败案例与两边耗时/用量；允许没有提升。
4. 用户验收里程碑后再添加版本标签。
